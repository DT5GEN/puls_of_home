# Пульс дома (puls_of_home)

Интерактивный дашборд для жильцов многоквартирных домов. Статус дома на 3D-модели (цвет окна показывает состояние квартиры), заявки с подтверждением, архив решений по категориям и общий чат дома.

**Статус:** этап проектирования. Код приложения ещё не написан. Готовы ТЗ, схема дома, промпт для первого этапа и 3D-референс.

## С чего начать

1. `CLAUDE.md`: правила проекта для Claude Code.
2. `docs/HISTORY.md`: контекст и история решений.
3. `docs/TZ_dom_status.md`: ТЗ.
4. `docs/prompts/01_model_and_tests.md`: промпт для этапа 1.
5. `docs/prototype/house3d_g_shape.html`: 3D-референс интерфейса (открыть в браузере).
6. `OPEN_QUESTIONS.md` и `docs/legal_questions.md`: нерешённые вопросы.

## Схема дома

```
python3 tools/gen_dom_draft.py
```

Команда создаёт `docs/dom_draft.json`. Значения адреса в скрипте временные.
